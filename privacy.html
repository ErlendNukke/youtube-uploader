Privacy policy

Living World Uploader is a private tool used only by the owner of The Living World YouTube channel.

It uses Google sign-in to get permission to upload videos and read basic channel information on the owner's own YouTube channel. It uses this access only to upload, schedule and add thumbnails to the channel's own videos.

It does not collect, sell or share data about anyone else. The access token is stored only on the owner's private computer and can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
