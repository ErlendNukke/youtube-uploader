Privacy policy

Erlend Nukke YouTube Uploader is a private tool used only by Erlend Nukke for his own YouTube channels.

It uses Google sign-in to get permission to upload videos and read basic channel information on the owner's own channels. It uses this access only to upload, schedule and add thumbnails to those channels' own videos.

It does not collect, sell or share data about anyone else. Access tokens are stored only on the owner's private computer and can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
